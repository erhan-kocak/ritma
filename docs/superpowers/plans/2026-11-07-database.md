# Kalıcı Veritabanı (PostgreSQL) Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Randevu verisini bellekten Neon PostgreSQL'e taşımak; API davranışı değişmeden.

**Architecture:** `pg.Pool` + şemayla nitelenmiş elle yazılmış SQL (`createPgStore({ pool, schema })`). Tablolar `db/migrations/*.sql` göçleriyle kurulur; `db/schema.sql` katalogdan otomatik üretilir. Çift randevuyu `exclude using gist` kısıtı engeller. Testler aynı veritabanında `ritma_test` şemasında, sırayla çalışır.

**Tech Stack:** Node.js 24, Express 5, TypeScript 5.9 (yalnızca tip kontrolü), `pg` 8.23, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-07-database-design.md`

## Global Constraints

- Build adımı yok; Node `.ts` dosyalarını doğrudan çalıştırır. Yalnızca silinebilir TS sözdizimi (`enum`, `namespace`, constructor parametre özelliği yok). Göreli import'lar `.ts` uzantılı.
- Yeni npm paketi yok (`pg`, `@types/pg` zaten kurulu).
- Şema adları yalnızca `"ritma"` (uygulama) ve `"ritma_test"` (testler). Tablo boşaltma yalnızca `ritma_test`'te.
- Saat dilimi sabit `Europe/Istanbul` (`+03:00`); tarih/saat hesapları `server/src/domain/time.ts` ile. `Date.parse`'a saat dilimsiz değer verilmez.
- API hata mesajları ve script çıktıları Türkçe. Dosya/klasör adları İngilizce.
- `.env` hiçbir yolla okunmaz/yazdırılmaz. Node onu `--env-file-if-exists=.env` ile kendisi yükler.
- Backend TDD: test önce. Her görevden sonra `npm test` ve `npm run typecheck` geçmeli.
- API yolları, yanıtları ve hata kodları değişmez; `openapi.ts` dokunulmaz.
- `npm test` için `DATABASE_URL` gerekir (kullanıcı `.env`'e koydu; değeri sorulmaz, yoksa testler Türkçe hatayla düşer).

## Review Focus

1. **Neon boşta duran bağlantıyı kapatır** → `pg.Pool` `error` olayı dinlenmezse süreç çöker. Beklenen: hata loglanır, sunucu çalışmaya devam eder. (Görev 2'de `pool.on("error")` ve testi.)
2. **Windows'ta `db/schema.sql` CRLF ile çıkarılır** → güncellik testi satır sonları yüzünden yanlışlıkla düşer. Beklenen: karşılaştırma `\r\n`'i `\n`'e çevirerek yapılır, dosya LF yazılır. (Görev 3.)
3. **`btree_gist` ilk uygulanan şemaya kurulur** (`ritma_test` önce çalışırsa eklenti oraya düşer, test şeması silinince `ritma`'nın kısıtı bozulur). Beklenen: `create extension … with schema public`. (Görev 2'de test.)
4. **Tablolar henüz kurulmamışken `npm start`** → her istek 500 ve anlamsız log. Beklenen: sunucu açılışta `providers` tablosunu bulamazsa "Tablolar yok, `npm run db:migrate` çalıştırın" deyip kapanır. (Görev 6.)
5. **Aynı slota eşzamanlı iki istek** → ikisi de rota kontrolünü geçer. Beklenen: biri `201`, diğeri `409 slot_taken`, asla `500`. (Görev 5 depo, Görev 6 API.)
