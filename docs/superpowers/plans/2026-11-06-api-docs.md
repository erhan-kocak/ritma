# API Deneme Arayüzü (Swagger UI) Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend uç noktalarını `/api-docs/` adresindeki Swagger UI'den, hazır örneklerle denenebilir hale getirmek.

**Architecture:** `server/src/openapi.ts`, OpenAPI 3.1 belgesini her istekte `now`'a göre üretir (örnek tarih = bugünden sonraki ilk iş günü) ve `GET /api/openapi.json`'dan sunulur. `public/api-docs/index.html`, Swagger UI'yi jsDelivr'dan (sabit sürüm + SRI) yükleyip bu belgeyi gösterir. Testler belgedeki yolların router'la eşleştiğini ve örneklerin belgelenen durum kodlarını döndüğünü denetler.

**Tech Stack:** Node.js 24, Express 5, TypeScript 5.9 (build yok), `node:test`; Swagger UI `swagger-ui-dist@5.17.14` (CDN).

**Spec:** `docs/superpowers/specs/2026-11-06-api-docs-design.md`

## Global Constraints

- Yeni npm paketi yok. Swagger UI yalnızca CDN'den ve yalnızca `public/api-docs/` içinde.
- Yalnızca silinebilir TypeScript sözdizimi (`enum`, `namespace`, parametre özellikleri yok); göreli import'lar `.ts` uzantılı.
- Tarih hesapları `server/src/domain/time.ts` ile; `Date.parse`'a saat dilimsiz değer verilmez. Saat dilimi `Europe/Istanbul` (`+03:00`).
- Tüm açıklamalar, başlıklar ve hata mesajları Türkçe; dosya adları İngilizce.
- Renkler `public/styles.css` `:root` değişkenlerinden.
- Test önce (TDD). Her görev sonunda `npm test`, `TZ=UTC npm test`, `npm run typecheck` geçer.
- Commit mesajları Türkçe, sonu: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Hafta sonu ya da akşam açılan sunucu:** "şu an" Cumartesi ya da Cuma 20:00 iken de örnekler beklenen kodları döner (11:00 hâlâ boş ve gelecekte). → Görev 2, örnek testi üç farklı `now` ile.
2. **Yanlış nedenle 400:** "11:07" ve "19:00" örnekleri `invalid_request` değil `invalid_slot` dönmeli; aksi halde örnek başka bir şeyi denetliyor olur. → Görev 2, hata kodu da `x-expected-code` ile denetlenir.
3. **`/api` yakalayıcısı belgeyi yutması:** `/api/openapi.json` 200 dönmeli, `/api/olmayan` hâlâ 404 JSON. → Görev 1.
4. **`/api-docs` (eğik çizgisiz):** yönlendirmeyle sayfaya ulaşır. → Görev 3.
5. **Swagger'ın gövde örneğini değiştirmesi:** POST örnekleri sırayla gönderilince 2. örnek 409 verir; 1. örnek yeni bir sunucuda 201 verir. Sıra belgeye nesne anahtar sırasıyla yazılır ve JSON'da korunur. → Görev 2.

### Task 1: OpenAPI belgesi iskeleti ve sunumu

**Files:**
- Modify: `server/src/domain/time.ts`
- Create: `server/src/openapi.ts`
- Modify: `server/src/app.ts`
- Test: `server/test/time.test.ts` (mevcut dosyaya ekle), `server/test/openapi.test.ts` (yeni)

**Interfaces:**
- Consumes: `addDays`, `dayOfWeek` (1 = Pazartesi … 7 = Pazar), `localDateOf` from `time.ts`; `providersRouter(store, now)`; `startTestServer`, `TEST_NOW`, `testData` from tests.
- Produces:
  - `nextWorkingDayAfter(date: string): string` (`time.ts`): `date`'ten sonraki ilk Pazartesi–Cuma günü (`YYYY-MM-DD`).
  - `createOpenApiDocument(now: Date): OpenApiDocument` (`openapi.ts`).
  - `type OpenApiDocument = { openapi: "3.1.0"; info: { title: string; version: string; description: string }; paths: Record<string, Partial<Record<"get" | "post", Operation>>>; components: { schemas: Record<string, unknown> } }`
  - `type Operation = { summary: string; description?: string; parameters?: Parameter[]; requestBody?: RequestBody; responses: Record<string, { description: string; content?: unknown }> }`
  - `type Parameter = { name: string; in: "path" | "query"; required: boolean; description: string; schema: unknown; example: string }`
  - `type RequestBody = { required: true; content: { "application/json": { schema: unknown; examples: Record<string, BodyExample> } } }` (`BodyExample` Görev 2'de doldurulur; bu görevde `examples: {}`).

- [ ] **Step 1: `nextWorkingDayAfter` için başarısız testleri yaz**

```ts
test("nextWorkingDayAfter: hafta içi ertesi gün", () => {
  assert.equal(nextWorkingDayAfter("2026-10-28"), "2026-10-29"); // Çarşamba → Perşembe
});
test("nextWorkingDayAfter: Cuma, Cumartesi ve Pazar → Pazartesi", () => {
  assert.equal(nextWorkingDayAfter("2026-10-30"), "2026-11-02");
  assert.equal(nextWorkingDayAfter("2026-10-31"), "2026-11-02");
  assert.equal(nextWorkingDayAfter("2026-11-01"), "2026-11-02");
});
```

- [ ] **Step 2: Belge sunumu için başarısız testleri yaz** (`openapi.test.ts`, `createApp({ store: createMemoryStore(testData()), now: () => TEST_NOW })`)

```ts
test("GET /api/openapi.json OpenAPI 3.1 belgesini döner", async (t) => {
  // status 200, content-type /application\/json/, body.openapi === "3.1.0",
  // body.info.title === "Ritma API"
});
test("/api yakalayıcısı hâlâ çalışır", async (t) => {
  // GET /api/olmayan → 404, body.error.code === "not_found"
});
test("belgedeki yollar router'daki rotalarla birebir aynı", async (t) => {
  const fromRouter = providersRouter(createMemoryStore(testData()), () => TEST_NOW).stack
    .flatMap((layer) => Object.keys(layer.route!.methods).map(
      (m) => `${m.toUpperCase()} /api/providers${layer.route!.path.replace(/:(\w+)/g, "{$1}")}`));
  const fromDoc = Object.entries(createOpenApiDocument(TEST_NOW).paths)
    .flatMap(([p, ops]) => Object.keys(ops).map((m) => `${m.toUpperCase()} ${p}`));
  assert.deepEqual(fromDoc.sort(), fromRouter.sort());
});
```

`layer.route` tipi `@types/express`'te yoksa test içinde dar bir tip dönüşümüyle (`as unknown as { route: { path: string; methods: Record<string, boolean> } }[]`) okunur; `any` kullanılmaz.

- [ ] **Step 3: Testleri çalıştır, başarısız olduklarını gör**

Run: `node --test server/test/time.test.ts server/test/openapi.test.ts`
Expected: FAIL (`nextWorkingDayAfter` / `createOpenApiDocument` yok, `/api/openapi.json` 404).

- [ ] **Step 4: Uygula**

- `time.ts`: `nextWorkingDayAfter`, `addDays` + `dayOfWeek` döngüsüyle.
- `openapi.ts`: `info.title = "Ritma API"`, `info.version = "0.1.0"`, Türkçe `info.description` (spec'teki giriş açıklaması: veriler bellekte, 1. örnek bir kez gönderilince o saat dolar, sunucu yeniden başlayınca örnek veriye döner). Spec tablosundaki 4 yol, Türkçe `summary` ve belgelenen yanıt kodlarıyla (`200/404`, `200/400/404`, `201/400/404/409`, `200/400/404`). Parametre `example` değerleri: `slug = "ayse-yilmaz"`, `serviceId = "nutrition-45"`, `date = nextWorkingDayAfter(localDateOf(now))`. Şemalar: `Provider`, `Service`, `Appointment`, `ErrorResponse` (`code` için `enum`: `invalid_request`, `invalid_slot`, `provider_not_found`, `service_not_found`, `slot_taken`, `not_found`, `internal_error`). Yanıtlar `$ref` ile bu şemalara bağlanır. POST `requestBody.content["application/json"].examples = {}` (Görev 2 doldurur).
- `app.ts`: `/api/providers` satırından sonra, `/api` yakalayıcısından önce `app.get("/api/openapi.json", (_req, res) => res.json(createOpenApiDocument(now())))`.
